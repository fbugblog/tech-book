# 第III部・応用AI/LLMアーキテクチャとRAG

デモが動くLLMアプリケーションと、業務で使えるLLMアプリケーションの間には、想像以上の距離がある。この部では、その距離を埋める設計を扱う。

第6章は検索の層——チャンキング、埋め込み、ハイブリッド検索、リランキング。第7章は出力の層——スキーマ駆動の構造化出力と、プロンプトをコードとして管理する方法。第8章は制御の層——エージェントの状態設計と、人間が介入する余地の作り方である。
