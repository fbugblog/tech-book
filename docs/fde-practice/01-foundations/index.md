# 第I部・FDEの思想とプラクティス

技術の話に入る前に、この職種が何を引き受けているのかを定義しておく。FDEは「顧客先に常駐するエンジニア」という配置の話ではなく、課題の発見から本番運用までを一人の視野に収める、責任範囲の設計思想である。

第1章では、既存の職種——ITコンサルタント、データエンジニア、ソフトウェアエンジニア——との境界線を引き、PoC貧乏に陥らないための「初日からプロダクションを見据える」プロトタイピングの作法を扱う。第2章では、顧客が口にする要望を、解ける形の問いに変換する技術と、AIで解くべきかどうかを判定する基準を扱う。
