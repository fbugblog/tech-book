# 第II部・エンタープライズ・データ基盤とモデリング

AIアプリケーションの品質は、その下にあるデータの品質を超えない。そして現場のデータは、たいてい想像より汚れている。

第3章では、サイロ化した基幹系、Excel運用、PDF帳票という三つの現実に処方箋を書く。第4章では、分析とAI活用の両方を支えるモデリング——ディメンショナルモデリングとData Vault 2.0、そしてセマンティックレイヤー——を設計判断の軸として整理する。第5章では、それらをdbtとオーケストレーターでコード化し、CI/CDに載せるまでを扱う。
