# 第IV部・システム開発・API・フロントエンド

FDEはフルスタックであることを求められる。ただし「あらゆる技術に精通している」という意味ではなく、「価値の流れを止める接続面を、自分で塞げる」という意味である。

第9章は非同期APIとストリーミング、第10章は数時間で作るプロトタイプと運用に耐えるダッシュボードの使い分け、第11章はオンプレミスの基幹システムと安全につなぐためのパターンを扱う。
