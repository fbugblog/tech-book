# 第27章 データとインフラの壁——科学データのガバナンスと基盤整備

前章では、AIの出力そのものの信頼性という問題を見てきた。この章では視点を変え、そのAIを支える土台——学習データと計算インフラ——が、どのように整備され、誰がそれにアクセスできるのかという、より構造的な問題に目を向ける。第I部から繰り返し確認してきたように、優れたAI for Scienceのシステムは、例外なく大量の高品質なデータの上に成り立っている。この土台が、実は思ったより脆く、そして不均等に分配されている、という現実を見ていきたい。

## 公開図書館か、それとも鍵のかかった書庫か

第11章のAlphaFold構造データベース、第13章のMaterials Project、第19章のESM3が学習に使った公開タンパク質配列データベース——本書でこれまで紹介してきた画期的な成果の多くは、無償で公開された大規模なデータベースの存在なしには実現しなかった。これらは、いわば人類共有の公開図書館のような存在であり、誰でも自由に本を借り出し、そこから新しい知識を紡ぎ出すことができる。

しかしすべての科学データがこのように開かれているわけではない。特に創薬の分野では、製薬企業が独自に蓄積してきた膨大な実験データ（どの化合物がどんな条件で失敗したか、という「陰性データ」を含む）は、競争上の理由から、それぞれの企業の中に厳重に鍵をかけて保管されている。この陰性データは、実は次に何を試すべきでないかを教えてくれる、AIの学習にとって非常に価値のある情報なのだが、企業間で共有されることはほとんどない。

> 科学の進歩の速度は、どれだけの知識が公開図書館を通じて共有されるか、それとも鍵のかかった書庫の奥に眠ったままになるかによって、大きく左右される。

## 「誰でも参加できる」科学から「巨大な資本を持つ者」の科学へ

もう一つの構造的な壁が、計算インフラへのアクセス格差だ。Auroraのような大規模な基盤モデルを一から学習させるには、莫大な計算資源と、それを賄う資金が必要になる。第20章で紹介した自律実験室の分野でも、大学の研究室発のプロジェクトに加えて、数十億円から百億円規模の資金を調達するスタートアップ企業が相次いで登場しており、この分野の競争の重心は、伝統的な大学の研究室から、潤沢な資金を持つ企業へと、部分的に移りつつある。これは、かつて誰でも自分の裏庭の実験室から始められた科学が、次第に大きな設備投資を必要とする「ビッグサイエンス」へと移行してきた歴史とも重なる構図だ。

## データの質を保証する、地味だが欠かせない仕事

データの「量」だけでなく「質」の管理も、見過ごされがちだが重要な課題だ。第8章で扱ったノイズの問題を思い出してほしい。異なる研究機関が異なる測定装置や実験プロトコルで集めたデータを一つのデータベースに統合する際には、測定条件の違いによる系統的なズレを丁寧に補正する作業が欠かせない。この地道なデータキュレーションの仕事は、華やかなモデル開発の陰に隠れがちだが、その質が低ければ、どれだけ優れたアーキテクチャを用意しても、砂上の楼閣になってしまう。

## 基盤づくりは、技術の問題であると同時に制度の問題でもある

データをどこまで公開すべきか、誰が計算インフラへの公平なアクセスを保証するのか、といった問いは、純粋な技術の問題であると同時に、研究資金の配分や国際協力のあり方といった、制度的な選択の問題でもある。この制度的な選択は、最終的には各国の政策や研究コミュニティの意思決定に委ねられている。次章では、この観点から、AI for Scienceをめぐる政策と倫理、そして人材育成の課題を見ていく。

::: tip この章のポイント
- AlphaFold構造データベースやMaterials Projectのような公開データベースは、この分野の進歩を支える公共財として機能してきた
- 製薬企業が持つ陰性データのように、価値がありながら競争上の理由から共有されないデータも多く存在する
- 大規模な基盤モデルの学習や自律実験室の構築には莫大な計算資源と資金が必要であり、研究の重心が大学から潤沢な資金を持つ企業へと部分的に移りつつある
- 異なる条件で集められたデータを統合するデータキュレーションという地道な作業が、データの質を保証する上で欠かせない
:::
