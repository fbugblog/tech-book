# 第2章 機械学習の基礎再訪——教師あり・教師なし・強化学習

前章では、AI for Scienceを「科学の第五の時代」として大づかみに捉え、道具としてのAIと主体としてのAIという整理軸を紹介した。この章からしばらくは、いったん技術そのものに目を戻す。読者の多くはすでに機械学習の基本的な枠組み——教師あり学習、教師なし学習、強化学習という三分類——をご存じだろう。ここでその説明を一から繰り返すつもりはない。その代わりに、この三分類を「科学研究という文脈に置いたとき、それぞれがどんな役割を担っているのか」という視点から捉え直したい。

というのも、AI for Scienceの面白さは、この教科書的な三分類が、そのまま研究プロセスの三つの局面と驚くほどきれいに対応している点にあるからだ。教師あり学習は「すでに答えが分かっている現象から法則を学ぶ」局面に、教師なし学習は「まだ誰も気づいていない構造やパターンを見つけ出す」局面に、そして強化学習は「試行錯誤を通じて最適な手順そのものを編み出す」局面に、それぞれ対応している。

## 教師あり学習——「高価なラベル」をどう使い倒すか

教師あり学習の本質は、入力とその正解ラベルのペアから、入力から出力への写像を学習することにある。科学の世界では、この「正解ラベル」の性質がしばしば特殊である。ある分子が特定の疾患に効く薬になり得るかどうかを知るには、実際に細胞実験や動物実験が必要になる。ある結晶構造が安定かどうかを知るには、量子化学計算を回す必要があり、一つの計算に数時間から数日かかることも珍しくない。

つまり科学分野での教師あり学習は、限られた数の高価なラベル付きデータから、いかに効率よく汎化性能の高いモデルを学習するか、という問題設定になる。この制約が、後の章で扱う「転移学習」や「基盤モデルの事前学習」という発想——大量の教師なしデータで下地を作っておき、少量の高価なラベル付きデータで仕上げの調整をする、という二段構えの戦略——につながっていく。

## 教師なし学習——データの中に隠れた地図を描く

教師なし学習は、正解ラベルを一切与えずに、データそのものが持つ構造やパターンを見つけ出す枠組みだ。科学研究において教師なし学習が真価を発揮するのは、「そもそも何を探しているのか、研究者自身がまだ分かっていない」局面だ。単一細胞シーケンシングという技術では、一つの実験で数万個の細胞について、数千種類の遺伝子の発現量が得られる。この膨大な高次元データの中に、研究者がまだ名前すら付けていない未知の細胞種が隠れているかもしれない。教師なし学習によって、似た発現パターンを持つ細胞同士を自動的にグループ分けし、それが本当に生物学的に意味のある新しい細胞種なのかを、後から実験で確かめる、という順番になる。

> 教師あり学習が地図を渡されて道を答える課題だとすれば、教師なし学習は見知らぬ土地の地形そのものを自分で見つけ出す課題に近い。

## 強化学習——「答え」ではなく「手順」を学ぶ

強化学習は、エージェントが環境に働きかけ、その結果として得られる報酬を手がかりに、より良い行動方針を試行錯誤を通じて学んでいく枠組みだ。科学分野における使いどころは大きく二つある。一つは、分子や材料の「設計」そのものを逐次的な意思決定問題として捉え直す使い方。もう一つは、実験そのものの計画を最適化する使い方だ。次にどの条件で実験すれば、最も効率よく目的の材料や反応条件にたどり着けるかを、試行錯誤の履歴から学習していく。

> 強化学習とは、味見を繰り返しながら自分のレシピそのものを作り替えていく営みだ。

第1章で紹介した「主体としてのAI」という考え方は、まさにこの強化学習的な発想——AIが試行錯誤を通じて自分なりの手順を編み出していく——と地続きになっている。

## 三つの枠組みは排他的ではない

この三分類はあくまで整理のための便宜的な区分であり、実際の研究システムでは複数の枠組みが組み合わさって使われることがほとんどだ。分子生成AIの多くは、生成モデルによって候補分子を作り出しつつ、その候補の良し悪しを強化学習的な報酬信号で磨き上げる、というハイブリッドな構成を取っている。

::: tip この章のポイント
- 教師あり学習は「答えの学習」であり、科学分野では正解ラベルが高価であることが特有の制約になる
- 教師なし学習は「構造の発見」であり、まだ名前も付いていない未知のパターンを見つけ出す局面で威力を発揮する
- 強化学習は「手順の獲得」であり、分子・材料の設計や実験計画の最適化に向いている
- 三つの枠組みは排他的ではなく、実際のシステムでは組み合わせて使われることが多い
:::
