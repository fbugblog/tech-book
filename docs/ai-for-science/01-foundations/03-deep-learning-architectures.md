# 第3章 深層学習アーキテクチャの基礎——CNN・RNN・Transformer

前章では、教師あり学習・教師なし学習・強化学習という三つの枠組みを、それぞれ「答えの学習」「構造の発見」「手順の獲得」として整理した。だがこれらはあくまで「何を学ぶか」という目的の話であり、「データをどう処理してその目的を達成するか」という手段の話は、まだ何も語っていない。この手段にあたるのが、深層学習のアーキテクチャ——ニューラルネットワークの「配線図」そのものだ。

## CNN——「虫眼鏡で地図をなぞる」ように局所パターンを拾う

CNNは、画像のような格子状のデータを処理するために設計されたアーキテクチャだ。その核となる仕組みは「畳み込み」と呼ばれる操作で、小さな窓を画像全体にスライドさせながら、窓の中に写っている局所的なパターンを検出していく。

> CNNがしているのは、虫眼鏡で地図をなぞりながら、局所的な地形を大域的な構造へと組み上げていく作業だ。

科学分野でCNNが活躍する場面は幅広い。クライオ電子顕微鏡で撮影された生体分子の画像解析、天体望遠鏡が捉えた銀河の分類、衛星画像を使った氷床の変化の検出など、「空間的な広がりを持つ観測データ」を扱う場面のほとんどで、CNNは今でも基本的な選択肢の一つであり続けている。

## RNN——時間の流れを「記憶」しながら読み進める

RNNは、時系列データや系列データのように、要素の並び順そのものが意味を持つデータを扱うために考え出されたアーキテクチャだ。データを順番に処理しながら、それまでに読んだ内容を「隠れ状態」という形で内部に保持し続ける。ところがこの仕組みには弱点がある。系列が長くなると、はるか昔の情報をうまく記憶し続けられなくなる「勾配消失問題」だ。LSTMやGRUといった改良版アーキテクチャは、この弱点を克服するために考案された。

## Transformer——全員が全員を見渡す「注意」の仕組み

RNNの逐次処理は並列化しにくく、大規模なデータで学習するのに時間がかかるという弱点があった。この弱点を克服するために2017年に提案されたのがTransformerであり、その中核にある仕組みが「注意機構（Attention）」である。

> Transformerの注意機構は、円卓を囲む研究者たちが互いにどれだけ耳を傾けるかを動的に調整するように、系列内の要素同士の関係を捉える。

この注意機構は、自然言語処理の世界を一変させただけでなく、科学データの解析にもそのまま応用できることが分かってきた。タンパク質のアミノ酸配列はその典型例だ。系列の上では遠く離れていても、立体構造の中では重要な関係にあるアミノ酸のペアが存在する。AlphaFoldの中核をなす「Evoformer」は、この注意機構を応用して、そうしたペアを直接捉えられるように設計されている。

## アーキテクチャは「組み合わせて」使うのが当たり前になった

現在の実践では、CNN・RNN・Transformerを排他的に選ぶのではなく、データの性質に応じて組み合わせて使うことが当たり前になっている。第14章で扱う気象基盤モデル「Aurora」も、このような複合的なアーキテクチャの発想の延長線上にある。

::: tip この章のポイント
- CNNは画像のような格子状データに強く、局所パターンを段階的に組み合わせて大域的な構造を捉える
- RNNは時系列・系列データに強いが、系列が長くなると過去の情報を記憶し続けにくいという弱点がある
- Transformerの注意機構は、系列内のすべての要素同士の関係を並列に捉えられ、AlphaFoldのEvoformerをはじめ科学分野に広く応用されている
- 実践では複数のアーキテクチャを組み合わせたハイブリッド構成が一般的である
:::
