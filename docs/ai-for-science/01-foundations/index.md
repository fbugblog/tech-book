# 第I部・基礎編

AI for Scienceを読み解くための技術的な語彙を、一つずつ積み上げる。学習の枠組みからアーキテクチャ、表現、生成モデル、グラフ、物理法則の組み込み、科学データ固有の壁、そしてシミュレーションとの融合まで。最後に、これらの技術要素が研究プロセス全体のどこに位置づくのかを一枚の地図にまとめる。
