# AI for Science — 深掘り全30章

2024年のノーベル化学賞がAlphaFoldの開発者に贈られたとき、科学という営みの中でAIが占める位置が、はっきりと目に見える形で変わった。本書は、この変化——「AI for Science」と呼ばれる潮流——を、技術の基礎から分野別の応用、そして最前線の課題までたどる全30章の読み物である。

## 対象読者

- 機械学習やAIの基礎知識はすでに持っていて、それが科学研究の現場でどう使われているのかを知りたい人
- 特定の分野（創薬、材料、気象、物理、化学、数学、神経科学）でのAI活用の実例を、技術的な中身まで含めて追いたい人
- エージェント型AIや自律的発見といった最前線の話題を、誇張なしに整理して読みたい人

AIそのものの初歩的な説明は省いている。一方で、各分野の専門知識は前提にしていない。

## 三部構成

| 部 | 扱うこと |
| --- | --- |
| 第I部・基礎編（第1〜10章） | AI for Scienceを読み解くための技術的な語彙を揃える |
| 第II部・応用編（第11〜20章） | 分野ごとに、実在のシステムが何を成し遂げたのかを確かめる |
| 第III部・最前線編（第21〜30章） | 自律的発見の潮流と、評価・信頼性・政策という課題に向き合う |
